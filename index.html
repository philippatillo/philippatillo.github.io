A cross-platform mobile app from scratch, using React Native, Expo, React Navigation, and Context API for state management. I set up a PR-based GitHub workflow so a second developer's contributions could be reviewed and merged safely.

RSA Encryption System & Key Monitoring Tool

Built a working RSA cryptosystem from scratch — key generation, encryption, decryption, and cryptographic validation. Paired it with a Python monitoring tool that captures, timestamps, and logs security events using secure file handling practices.

  • Python
  • Cryptography

Read more

The problem

Using a cryptography library hides how public-key encryption actually works. I wanted to understand RSA well enough to implement it myself, not just call a function that does it.

What I built

A working RSA cryptosystem from scratch — key generation, encryption, decryption, and cryptographic validation — plus a companion Python tool that captures, timestamps, and logs security events using secure file handling practices.

What it reinforced

Building the math and the key management by hand made concepts like key size trade-offs and validation failure modes concrete in a way that using a library never would have.
